# Neural Network for Iris Flower Classification

## Tutorial Reference

This notebook was completed as part of **“Intro To Deep Learning With PyTorch - Deep Learning with Pytorch 1”** by **John Elder**. It was a helpful beginner tutorial for learning core PyTorch concepts, and This project implements a simple neural network to classify Iris flower species based on their sepal length, sepal width, petal length, and petal width. The neural network is built using Scikit-Learn and PyTorch and is trained on the well-known Iris dataset. I would highly recommend this tutorial to anyone looking to get started in deep learning 😊
